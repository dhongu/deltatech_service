1. In *Services > Configuration > Services Agreement Type*, tick *Allows non-billable
   deliveries* on the types whose agreements cover deliveries of consumables.
2. Assign the service agreement on the equipment.
3. Create a notification for the equipment: the *Service Agreement* field is filled in
   from the equipment.
4. On a notification with the *Delivery* category, use *New Delivery* to prepare the
   delivery; the button is hidden when the agreement type does not allow deliveries.
5. Create the service order from the notification or from the equipment: it receives
   the same service agreement.
